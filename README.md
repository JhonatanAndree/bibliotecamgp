# Biblioteca Virtual MGP

Repositorio del plugin propio de la biblioteca virtual del IESTP Manuel
Gonzales Prada (biblioteca.mgp.edu.pe).

- **`plugin/mgp-biblioteca-core/`** — el plugin de WordPress a subir a
  `wp-content/plugins/`. Ver instrucciones de despliegue en `MEMORIA.md §7`.
- **`docs/`** — plan de implementación y decisiones de diseño.
- **`MEMORIA.md`** — memoria del proyecto: contexto, decisiones tomadas y
  por qué, y qué falta. **Leer esto primero** antes de retomar el trabajo.

## Requisitos del sitio
- WordPress 6.4+, PHP 8.0+.
- Elementor (tema/diseño ya existente, no lo toca este plugin).
- Complementarios recomendados (no obligatorios): DearFlip Lite, Members,
  UpdraftPlus, Wordfence, FileBird.
